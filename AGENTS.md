# AGENTS.md — OmniWrap .NET / C# SDK (`jackai-dev/omniwrap-sdk-dotnet`)

## Overview
This repository contains the official **.NET / C#** SDK for **OmniWrap** (`v1.0.0`), deterministically generated by OmniWrap from `openapi.json`.

- **Install:** `dotnet add package JackAI.OmniWrap.Sdk`
- **API Reference:** See [`api.md`](./api.md) for every operation signature, parameter schema, and example.
- **OpenAPI Contract:** [`openapi.json`](./openapi.json)
- **Artifact Provenance:** [`omniwrap-artifact.json`](./omniwrap-artifact.json)

## Agentic Autonomy & Safety Rules
1. **Read-Only Operations (`L1` / Safe Retry):** All `GET` endpoints (`getUserContext`, `listProjects`, `getProject`, `listSourceRevisions`, `getSourceSummary`, `listJobs`, `getJob`, `listReleases`, `getEngineSummary`) are idempotent and safe for autonomous exploration.
2. **State-Mutating Operations (`L2` / Controlled Write):** Creating projects (`createProject`), uploading OpenAPI specs (`uploadSourceRevision`), enqueuing SDK generation jobs (`createJob`), and publishing releases (`createRelease`, `publishGithubSdk`) mutate workspace state and consume build quota where applicable.
3. **Destructive Operations (`L3` / Explicit Human Confirmation):** Removing source revisions (`deleteSourceRevision`) or revoking organization members requires explicit user confirmation.
