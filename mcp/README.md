# omniwrap MCP knowledge server

Read-only stdio [MCP](https://modelcontextprotocol.io) server generated by
OmniWrap. It answers knowledge queries about the API from the bundled
`library-ir.json` and the semantic contract `semantic-api.json` and never executes target code or network
requests.

Server name (the key under `mcpServers` in `mcp.json`): `omniwrap-knowledge`

## Launch

```
python server.py
```

`mcp.json` beside this file is the canonical client configuration. It launches
`server.py` relative to the working directory, so start the host from this directory or add a `cwd`. On macOS and Linux the
Python launcher is usually `python3`; replace `"command": "python"` with
`"command": "python3"` in the snippets below when `python` is not on `PATH`.

## Register with Claude Desktop

Add to `claude_desktop_config.json` (macOS:
`~/Library/Application Support/Claude/claude_desktop_config.json`, Windows:
`%APPDATA%\Claude\claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "omniwrap-knowledge": {
      "command": "python",
      "args": ["server.py"],
      "cwd": "<absolute path of this directory>"
    }
  }
}
```

## Register with Cursor

Add to `.cursor/mcp.json` in your project (or `~/.cursor/mcp.json` globally):

```json
{
  "mcpServers": {
    "omniwrap-knowledge": {
      "command": "python",
      "args": ["server.py"],
      "cwd": "<absolute path of this directory>"
    }
  }
}
```

## Register with Codex

Add to `~/.codex/config.toml`:

```toml
[mcp_servers.omniwrap-knowledge]
command = "python"
args = ["server.py"]
cwd = "<absolute path of this directory>"
```

Replace `<absolute path of this directory>` with the absolute path of this directory if the bundle
was moved or copied.
